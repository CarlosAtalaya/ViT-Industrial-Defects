# Fase 2 multimodal (material exploratorio)

Este fichero sustituye un documento largo de planificación interna. La experimentación **multimodal** (fusión texto–imagen sobre DEIMv2) se desarrolló de forma exploratoria; el código y notas de implementación están repartidos en:

- `demo-Multimodal/fase2_progressive_p2/` — entrenamiento progresivo y evaluación
- `demo-Multimodal/finetuning-simple-incremental/` — fine-tuning incremental sobre el detector
- `scripts/deimv2_multimodal/` — scripts de entrenamiento/evaluación DEIMv2 y, donde aplique, módulos multimodales

Para la línea principal del TFG (baselines CNN + DEIMv2 supervisado), prioriza la documentación en la raíz del repositorio, `scripts/deimv2_multimodal/README.md` y `herramienta_comparativa/`.
