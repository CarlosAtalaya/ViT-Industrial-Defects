Hola, quiero darte mucha contextualizacion de un proyecto de investigacion. Es una Investigacion TFG ViT aplicado a defectos industriales.
Es una linea de investigacion basada en computer vision para demostrar que nuevas arquitecturas basadas en ViTs son mucho mejores para la detección de defectos en distintos componentes industriales en comparación con arquitecturas clásicas como resnet18 o efficientnet.

Prompt de Contexto para TFG - Vision Transformers en Detección de Anomalías Industriales
Proyecto
TFG sobre detección de anomalías en componentes industriales usando Vision Transformers (ViT) con DINOv3. El objetivo es aplicar transfer learning con DINOv3 para superar las limitaciones de arquitecturas CNN tradicionales en defectos pequeños.

El proyecto actualmente se encunetra en una fase avanzada donde ya se han realizado varias iteraciones de entrenamiento con las arquitecturas tradicionales de resnet18, efficientnet y con deimv2 junto con dinov3 muchas pruebas.

Resumen de implementación con DEIMv2 + extensión multimodal

1) Entrenamiento inicial (visión pura)
Se utiliza DEIMv2 como detector base, empleando DINOv3 como backbone preentrenado y entrenable.
El modelo se entrena con el dataset etiquetado con bounding boxes para todas las clases de defectos.
Se aplican augmentations multiescala y se ajusta la red para mejorar el rendimiento en defectos pequeños.
Este entrenamiento produce un detector inicial sólido y sirve como baseline.

Esta fase ha sido completada con exito, indicándose en el documento deimv2_arquitetcura_implementacion.md toda la fase de experimentacion hecha aportando resultados de las metricas en la evaluacion de los distintos experimentos.

2) Construcción de la capa multimodal
Para cada clase del dataset (perforaciones, rayones, rotura, etc.) se redactan descripciones cortas en lenguaje natural (“Grieta fina y alargada”, “Perforación circular en la superficie”, etc.).
Se extraen embeddings de texto utilizando un encoder textual de la familia DINOv3/CLIP/SigLIP.
El backbone visual de DEIMv2 genera embeddings visuales para cada región propuesta en la imagen (ROI).

3) Fusión visión–lenguaje
Se implementa un módulo de similitud (por ejemplo, proyección lineal + normalización) que compara embeddings visuales y embeddings textuales para refinar la clasificación del detector.
El modelo aprende a alinear regiones visuales con las descripciones semánticas, permitiendo una clasificación más robusta de defectos difíciles o visualmente similares.

4) Entrenamiento conjunto (fine-tuning multimodal)
Se reentrena la cabeza de clasificación del detector utilizando una pérdida combinada que incluye similitud visión-texto y la pérdida de detección tradicional.
Esto mejora especialmente las clases con alta variabilidad visual o patrones muy sutiles.

5) Resultado final
El modelo mantiene las capacidades de detección de DEIMv2, pero incorpora un componente semántico que ayuda a distinguir defectos de forma más precisa.
Se obtienen mejoras en recall, precisión y robustez, especialmente en defectos pequeños o mal diferenciados visualmente.
